Value I Can Deliver

What I bring to a team and an organisation.

Modular cloud systems

Designing, developing, and deploying modular cloud-based systems. Over the last 5 years at Sainsbury's I created and managed Terraform-coded infrastructure on AWS and Helm and Flux-managed containerised applications on AWS EKS, including monitoring, logging, alerting, and connectivity.

Leadership & open source

Beyond my day job, I led a Cloud Engineering Community that voluntarily built an open-source learning platform on Google Cloud. It developed my leadership and design skills and gave me the experience of creating something new from scratch.

Cost reduction

Reduced cloud costs by more than 16% on average over the last year. Read how I did it.

Troubleshooting & security

Identifying, analysing, and resolving infrastructure vulnerabilities and deployment issues in line with company security policies and cloud security best practices.

For example, an app with a frontend, backend, authentication, and database had an authentication issue somewhere between DNS, CloudFront, WAF, OAuth2, Azure Entra ID, and the backend. Understanding every component led to the root cause: a WAF payload limitation.

Continuous improvement

Reviewing existing systems and recommending improvements. I like tools that show me what I am missing: I found zizmor, which scans GitHub Actions workflows for security issues, and applied all its suggestions across our existing workflows, making them more secure.

Automation

I recently automated Confluent Cloud secret rotation: it retrieves and decrypts the secrets, compares them with the current credentials, and when they change renews the HashiCorp Vault and AWS Secrets Manager secrets, without exposing any secret. It also restarts the Kubernetes pods so they pick up the renewed secrets.

CI/CD pipelines

Creating and improving CI/CD pipelines, including integration, operations, management, and maintenance. With GitHub Actions, CircleCI, and Jenkins I have created "miracles" (the developers' word) for tedious but necessary jobs.

Scripting

Building scripts and processes that reduce barriers, decrease friction, and speed up delivery, mostly with Bash and Python. I have yet to see a case where Bash could not do the job.

Bridging Dev and Ops

Collaborating with and providing technical assistance to operations and developer teams on microservices, deployment strategies, cloud architecture, and cloud resources, filling the gap between the two as DevOps intends.

Capacity planning

Planning cloud infrastructure capacity, which requires a true understanding of a service's purpose, requirements, expectations, limitations, cost, and business context.

Clear communication

Presenting complex technical infrastructure in a simple, easy-to-understand way, especially for non-technical colleagues and customers.
